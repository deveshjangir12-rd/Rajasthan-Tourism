# Rajasthan — The Royal State

A responsive Rajasthan travel discovery website built with React, Vite and React Router.

## Features
- Editorial homepage with cinematic hero, searchable destinations, experience cards, travel inspiration and planning CTA.
- Eight destination pages: Jaipur, Udaipur, Mount Abu, Jawai, Pushkar, Jaisalmer, Jodhpur and Bikaner.
- Reusable destination template with overview, facts, attractions, experiences, sample itinerary, food notes, travel info and related places.
- Responsive navigation, destination search, save toggle, route-aware pages and custom local SVG illustrations.
- Ivory sandstone, navy, antique gold and terracotta visual theme, elegant typography and subtle animations.

## Run locally
Requires Node.js 18+.

```bash
npm install
npm run dev
npm run build
```

The destination facts and itineraries are starter content; verify opening hours, seasonal conditions and event dates before travel. SVG art is locally stored illustrative artwork and can later be replaced with approved high-resolution photography without changing the page system.

## Deployment
Works on Vercel, Netlify, or any static host configured to route SPA requests to `index.html`.
